# Sign-in background

The Business sign-in screen shows the approved ShinaCare logistics photograph on its visual side.
Drop the **standalone** image here as `logistics.webp` (or `.jpg` / `.png`), roughly 1600×1800, dark
amber, **no text or UI baked in**. It is picked up automatically (the page checks for it at request
time); there is no code change.

It must be the original image, not a crop of a screenshot of the login screen. While no file exists
the screen renders a neutral amber atmosphere instead — no unrelated stand-in photo is used.
